# Historical original FEM documents

These exact text snapshots preserve the original mixed FEM/SutureBot guides,
equations, validation narrative and notices before the user-authorized
SutureBot cleanup of `newton-solver-fem` on 2026-11-10. The `.txt` suffix keeps
old commands and links from being presented as current standalone instructions.
Use the main standalone guides for setup and current implementation scope.

[manifest.json](manifest.json) records hashes and the destinations of removed
media/reports. Existing identical copies were reused; unique artifacts were
archived here. The larger pre-cleanup source snapshot is preserved separately
at ignored `results/fem-cleanup/before-cleanup.tar.gz`.
